### Reflexion

El reto más significativo de este ciclo académico radicó en la evolución del análisis descriptivo hacia la inferencia paramétrica. La programación en Google Colab con Python
—mediante las bibliotecas scipy.stats y statsmodels— exigió comprender que estas herramientas operan bajo estrictos fundamentos matemáticos, desmontando la idea del software 
como una simple caja negra. Asimismo, el dominio del valor-p y el análisis visual de los intervalos de confianza con la prueba de Tukey HSD resultaron fundamentales. Este
proceso permitio desarrollar el rigor analítico indispensable para evaluar de forma objetiva la significancia estadística de las brechas urbano-rurales dentro del conjunto de datos ambientales.
